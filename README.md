# DOTFILES
My Arch + Hyprland dotfiles!

<br>

## Dependencies

* **Hyprland** - Window manager
* **Hyprlock** - Lock Screen
* **Hyprshot** - Screenshot tool
* **Hypridle** - Idle Deamon
* **Kitty** - Terminal emulator
* **Zsh** - Terminal Shell
* **Waybar** - Status bar
* **Rofi** - Application launcher, powermenu, and clipboard interface
* **SwayNC** - Notification daemon
* **Matugen** - Material UI colors generated from wallpapers
* **Neovim** - Terminal IDE
* **awww** - Wallpaper manager
* **wl-clipboard** - Wayland clipboard tools
* **cliphist** - Clipboard history
* **xdg-desktop-portal-hyprland** - Required for screen sharing on Wayland

```bash
sudo pacman -S --needed hyprland hyprlock hyprshot hypridle kitty zsh waybar rofi-wayland swaync matugen neovim awww wl-clipboard cliphist xdg-desktop-portal-hyprland
```

<br>

## Fonts

* **Adwaita Sans** - System UI
* **JetBrains Mono Nerd Font** - Terminal + Icons *(Any Nerd Font is strictly required for the icons to render!)*

```bash
sudo pacman -S --needed ttf-jetbrains-mono-nerd adwaita-fonts
```

<br>

* **Apple Emoji** - Emojis *(You can substitute this with any emoji font)*
  
```bash
yay -S ttf-apple-emoji
```

## Get Started

git clone [https://github.com/kaunkrishna/dotfiles.git](https://github.com/kaunkrishna/dotfiles.git)
